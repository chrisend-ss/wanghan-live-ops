# 调用示例

以下是虚构教学场景，不是王焓实际直播结论。

## 视觉方案，无数据

输入：使用 $wanghan-core-ops，判断银发深色背景和黑发亮背景哪套更容易拉新。只有效果图，没有直播数据。

期望：归类①＋②，主功能进房；不能按审美选胜者。两套同时改变发色和背景，只能当组合实验。若要分别归因，先固定背景测发色。主指标选同来源曝光进房率，新人60秒留存作护栏；没有曝光数据先补后台口径并跑基线。运营部门审查应标记：当前只是视觉包装，不得据此推断“王焓真人更清冷”；结论为“仅可做实验假设”。

## 有进房数据，但留存变差

输入：使用 $wanghan-core-ops 复盘两种开场。A同来源曝光10,000人、进房500人，B曝光10,000人、进房600人；可完整观察60秒的新人队列A 400人、留存240人，B 500人、留存250人。两场日期不同，B多了PK。

期望：归类②、关联④/⑧，主功能进房，护栏留人。进房率5%→6%，增加1个百分点、相对20%；新人60秒留存60%→50%，下降10个百分点。运营部门审查：B存在PK混杂和“视觉/开场吸进来但内容承接不足”的风险，不能直接推广；判“需调整/复测”。

## 女性向中医选题

输入：使用 $wanghan-core-ops 设计“加班后的陪伴”主题验证，不要具体话术。

期望：③＋④，主功能留人，次功能关系；围绕真实履历和受众问题提出栏目假设，不给个体诊疗建议。运营部门审查同时检查：是否把中医做成权威诊断、是否吞掉唱歌身份、是否符合真实王焓；通过后再设计指标。

## 消费与粘性

输入：使用 $wanghan-core-ops，有脱敏观看、礼物、复访和内容偏好记录，想拆群。

期望：⑤＋⑦，以消费层级交叉歌粉、形象偏好、陪伴/性格与活动偏好；动机依据行为或自述，不凭昵称。运营部门审查必须检查高付费依赖和情绪债务风险，不能把“刷得多”直接等同于“最重要用户”。

## 切片播放高，但回流未知

输入：使用 $wanghan-core-ops，这条切片播放10万，要不要继续放大？没有回流来源数据。

期望：⑥＋⑧，主功能扩散；播放只说明触达。运营部门审查把高播放列为三级结果，不直接证明直播回流、真人特质或长期价值；补完播/分享、可靠回流标记和回流留存。

## 只有录屏复盘

输入：使用 $wanghan-core-ops，录屏第20分钟开灯，评论突然增多，没有后台数据。

期望：⑧关联①/②；录屏和可回溯转写属于一级事实，但“评论增多”只能证明内容反应，不能推出曝光进房、60秒留存或流水提升。运营部门审查标记数据缺口。

## 跨插件：先转写，再做战略复盘

输入：我给一个B站直播录屏链接，先分析主播真实说话，再结合直播数据做新分支核心运营复盘。

期望：
1. 若 `wanghan-live-review` 可用，先用它完成转写、说话/唱歌/背景音区分、王焓说话识别与时间轴。
2. 将可回溯原始片段和时间点作为一级事实输入 `wanghan-core-ops`。
3. 本 Skill 再做八大模块归类、数据对齐、运营部门审查与下一轮实验。
4. 自动转写给出的“人格总结”不能不经审查直接升级为长期人设。

## 跨插件：Drive 里的运营文档

输入：用核心运营 Skill 审一下我 Drive 里的最新王焓方案。

期望：优先读取 Google Drive 原文，不要求用户重新粘贴；如同名多版本，先确认最新版本和日期。历史方案是证据材料，但不能覆盖更新的一手录屏和后台数据。

## 外部样本 / vidIQ

输入：找几个公开视频拆开场钩子，看看能不能迁移到王焓。

期望：vidIQ 或公开网页用于拆外部样本；输出“可迁移假设”，而不是“行业都这么做，所以王焓应该这么做”。最终仍要回到王焓直播 A/B 和后台数据验证。

## 用户明确要求话术

输入：使用 $wanghan-core-ops，先判断这个选题的运营功能，再帮我写30秒开场话术。

期望：先做战略判断和运营部门审查，再按明确授权写对应话术，并给后续验证指标。新写的话术属于方案，不得反过来当成真实人格证据。
