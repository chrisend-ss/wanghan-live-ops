# 运营部门审查规则

本文件是“新分支核心运营思路”的内部审查层。它不与八大战略模块抢决策权，而是在战略方案形成后检查：证据是否站得住、是否符合真实王焓、是否存在过度包装、是否可验证、是否会带来关系或执行风险。

## 一、证据金字塔

### 一级事实
来源：
- 真实直播 / 原始录屏
- 真实访谈
- 可回溯逐字稿
- 抖音等后台真实数据

允许：
- 定真人行为
- 定真实语言习惯
- 定实际流量 / 留存 / 互动 / 消费事实
- 推翻旧版假设

### 二级证据
来源：
- 从一级事实提炼的受控总结
- 粉丝投稿
- 评论反馈
- 运营多人观察记录

允许：
- 验证稳定倾向
- 验证用户认知
- 作为选题和关系方向线索

不允许：
- 单独证明稳定人格
- 单独证明数据效果

### 三级结果
来源：
- 高赞二创
- 高传播切片
- 活动结果
- 外部平台公开视频表现

允许：
- 判断传播价值
- 判断是否值得复测
- 生成下一轮实验假设

不允许：
- 直接证明真人性格
- 直接证明长期留存和付费价值

### 禁止倒灌
以下只能做创作和包装，不能当成真人证据：
- 活动稿
- AI 人设稿
- OC 世界观
- 宣传文案
- 运营写的理想话术
- 海报设定

## 二、事实 / 推断 / 假设

每份审查必须尽量拆成三层：

**事实**：能够指出原始来源、时间点、后台字段或原话。

**推断**：由多个事实解释出的工作结论，必须说明推断链。

**假设**：尚未被充分验证，但值得设计实验测试的方向。

如果无法判断，就写“证据不足”，不要为了让方案完整而填满空白。

## 三、真人一致性

第一原则：先像真实王焓，再允许运营放大。

当前已经可以作为底层约束使用的方向：
- 唱歌是职业底盘
- 现实处理与关系边界优先于强情绪营业
- 视觉高级可以放大，但不能用视觉倒推真人“清冷”
- 中医是履历与功能差异，不是唯一产品
- 关系内容适合用环境和人物制造“球”，再让王焓真实接球

凡是要求主播持续扮演与真实反应明显相反的性格，优先判为“需调整”或“仅可做实验假设”。

## 四、固定审查维度

每次至少检查：

1. **证据等级与可信度**
   - 主要结论由几级证据支持？
   - 样本是否跨场次、跨场景？
   - 是否存在只挑好看的样本？

2. **真实王焓一致性**
   - 是放大已有特征，还是创造不存在的人格？
   - 是否要求主播持续演戏？

3. **人设倒灌 / 过度包装**
   - OC、古风、红线、悬丝、太医是否反向定义真人？
   - 世界观黑话是否压住真实内容？

4. **新人认知成本**
   - 陌生人能不能在短时间理解“他是谁 / 现在在干什么 / 为什么值得继续看”？
   - 是否需要大量老粉语境才能理解？

5. **唱歌主身份**
   - 方案最终有没有回到歌手价值？
   - 中医、关系局、视觉活动是否把唱歌挤成装饰？

6. **关系边界 / 粉丝压力**
   - 是否出现“证明爱”“不刷就是不支持”等隐性压力？
   - 是否过度制造占有感、男友义务或情绪债务？

7. **数据可验证性 / 归因**
   - 主指标是否真能回答目标？
   - 是否同时改了太多变量？
   - 是否把峰值 / 播放量 / 流水当成所有问题的答案？

8. **执行风险**
   - 主播是否能自然完成？
   - 团队是否有素材、时间、插件、后台字段支持？
   - 是否需要补最小数据后再做结论？

## 五、常见风险

| 风险 | 典型表现 | 主要监控信号 |
|---|---|---|
| 强行男友营业 | 高浓度占有、依赖、逼证明 | 主播疲惫、话术僵硬、粉丝冲突 |
| OC 倒灌真人 | 世界观词比真实聊天还多 | 新人听不懂、真人越来越不像自己 |
| 强迫主动整活 | 需要主播持续制造强刺激 | 尬、梗依赖脚本、主播消耗高 |
| 依赖关系嘉宾 | 嘉宾不在内容就掉 | 单播在线 / 留存断层 |
| 视觉吸错人 | 首屏很强但内容不承接 | 进房升、60秒留存降 |
| 高付费过度集中 | 流水看似高但新粉弱 | 老粉流水占比高，新粉首付和复访低 |
| 中医吞歌手 | 直播越来越像知识课堂 | 歌曲承接减少、歌粉深度下降 |
| 多变量混测 | 画面、开场、嘉宾、主题一起改 | 无法判断到底什么有效 |

## 六、审查结论

只使用三种内部结论：

### 通过
现有证据和真人边界足够支持执行；仍需按指标验证效果。

### 需调整
方向可以继续，但存在明确的人设、关系、认知、数据或执行问题，需要修改后再上。

### 仅可做实验假设
证据不足，不能当成长期方向。允许小成本、可回滚、可对照地测试。

审查结论不是“喜欢 / 不喜欢”，也不是替代直播数据的主观评分。
