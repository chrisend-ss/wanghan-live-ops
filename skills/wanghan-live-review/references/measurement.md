# 输入与指标口径

## 最小输入模板

```text
资料类型：直播数据 / 录屏复盘 / 视觉 / 活动 / 选题 / 切片
本轮目标：
直播日期、时区、时段：
资料来源和口径：
方案或内容节点（起止时间）：
录屏与实际直播时间偏移、误差：
基线/对照版本：
已知指标、分子分母、样本量：
流量来源、新老用户、投流/PK/活动等干扰：
执行资源、责任人、周期：
缺失项：
```

缺数据允许留空。仅有方案就设计实验，不补造历史表现。仅有录屏能分析内容节点与假设，无法确认平台曝光、留存或付费。

## 指标候选

| 功能 | 指标及建议口径 | 必要条件 |
|---|---|---|
| 进房 | 同来源同窗进房人数÷曝光人数 | 后台曝光与进房使用同种人数口径；若平台仅有次数，用次数口径并标注，不混算 |
| 留人 | 某进房队列持续观看≥60秒人数÷该队列进房人数 | 有用户观看时长/离房信息，剔除没有完整60秒观察机会的右删失用户，或等待观察窗完成 |
| 留人/关注 | 新增关注用户数÷同期未关注进房用户数 | 能辨认是否已关注；无此字段仅用平台原生转化口径，不能伪称新人转化 |
| 关系 | D日观看用户中D+1至D+7再观看人数÷D日观看用户数 | 稳定去重标识、完整后续7日观察窗；未成熟队列标待观察 |
| 关系 | 新入团人数÷同期未入团观看人数 | 能识别既有团员；否则报告人数及平台口径 |
| 互动 | 有效评论用户数÷同期观看用户数 | 去重，事前定义有效评论；弹幕条数不能当参与人数 |
| 消费 | 付费用户数÷观看用户数；人均付费=同窗收入÷付费人数 | 统一人数/收入口径、币种、退款和统计窗，至少同时报告付费人数 |
| 扩散 | 分享率、完播率、可归因回流人数及回流留存 | 平台同口径；来源标记/可靠归因才能判回流，无法归因时明确缺口 |

可用指标以平台真实字段为准。新人身份需按平台定义或明确历史窗口，不把“本分钟进房”直接称为“陌生用户”。收入、在线观看或弹幕峰值各自回答不同问题。

## 实验与结论记录

```text
实验ID/日期：
模块/功能/瓶颈：
证据与假设：
A/B版本/主要变量/控制条件：
实验单位、轮换顺序、时间窗与执行责任：
主指标（分子/分母/基线）：
辅助指标/护栏：
最低样本、重复周期、改善门槛、护栏容忍值及依据：
来源分层、执行偏差与混杂：
数据结果（含样本数与不确定性）：
判定：支持 / 否定 / 证据不足 / 未执行
保留/回滚/复测决定及限制：
下一轮变量、补数项、负责人、计划时间：
```

若以时间块轮换，时间块/场次是实验单位，观众可能重复出现，不能把每次进房都当独立随机样本。采用可比场次、平衡A/B顺序、多个时段重复，报告来源变化；用历史波动和所需最小实际改善制定样本计划。不要为凑显著结果随意延长、提前结束或事后更换主指标。

只有在样本、口径、可比性与护栏均满足预设条件时给出采用建议。数据充足且置信区间仍覆盖正负效果时也可以判证据不足。明显护栏损害可按预设停止规则暂停，不能宣称主效果已验证。
